# Domain specifications

Domain packages define named metric sources, JSON field mappings and Composer rules. Each selected domain needs a running Monitor and Composer.

The supplied packages describe the managed application, its external dependency and operating-system load. Thresholds and windows are configurable examples for those interfaces.

Select packages through [instance configurations](../../config/README.md). See [catalog extension](../../docs/extending-the-catalog.md) for new sources and local events.
