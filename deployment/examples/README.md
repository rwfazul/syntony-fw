# Runnable examples

- [Local service recovery](local/README.md): build and run the complete Syntony instantiation, then verify recovery of a supervised HTTP worker.
- [Metric acquisition](monitors/README.md): inspect actual HTTP, command and operating-system sources or publish their metrics through a Monitor.
- [Grid’5000](grid5000/README.md): provision reserved nodes, transfer sources and images, select module placement and check services.

Each guide lists its configuration, dependencies and execution commands. Adapt endpoint bindings, thresholds and action handlers to the target environment.
